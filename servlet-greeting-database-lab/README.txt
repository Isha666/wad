SERVLET LAB EXAM PACK — Based on servlets.docx

This ZIP includes TWO requested programs:
  GreetingServlet/  - welcome-name servlet (HelloServlet)
  DatabaseServlet/  - MySQL student name lookup (DatabaseServlet)

Each project has exactly THREE source files:
  index.html
  WEB-INF/web.xml
  WEB-INF/classes/<ServletName>.java

Each project also has a HOW_TO_RUN.txt guide.

Both use manual Tomcat 9 deployment and javax.servlet as in your document.
The original document calls the first project WelcomeServlet; this pack names
its directory GreetingServlet as requested. The servlet class is HelloServlet.

For the database program you must install MySQL Connector/J separately and
supply your MySQL credentials. The connector binary and compiled .class files
are not included; compilation is covered in the run guides.
